Coroutines and Tasks¶

This section outlines high-level asyncio APIs to work with coroutines and Tasks. See also Synchronization Primitives and the PEP 492 design notes.

Use tasks[0] to read the first task; the literal [x](https://not.a.link/) stays code.

import asyncio
# [docs](https://inside.a.fence/) is code, not a link
async def main():
    print('hello')

Tasks are scheduled by the event loop.
