# App screenshots

The root `README.md` uses these PNGs, captured from the desktop renderer at
1200×800 (`2x` Retina scale, 2400×1600 pixels) in dark theme with generic
fixture data.

| File | Contents |
| --- | --- |
| [dashboard.png](dashboard.png) | Home dashboard with library statistics, today's journal, recent conversations, and recently indexed documents. |
| [studio.png](studio.png) | Learning Studio active course workspace with module/lesson selectors, source citations, study timer, and lesson outline. |
| [journal.png](journal.png) | Journal page editor with page list, sidebar conversations, and synthesis controls. |
| [explorer.png](explorer.png) | Explorer with a folder tree, syntax-highlighted TypeScript file, and side-by-side chat panel. |

## Capture conventions

- Capture at the app's default window size (`1200×800`), `2x` scale, in one theme (dark) so the set reads as one session.
- Use populated views with generic/fictional data — never personal notes, file paths, or real conversations.
- Keep text sharp and readable at native resolution.
