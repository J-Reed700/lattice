# Restricted registries: suffixes under which only a vetted class of registrant
# may register a name, so the suffix itself says something about the publisher.
# One suffix and its class per line; the longest label-aligned match wins.
#
# Sources: the IANA Root Zone Database's sponsoring-organisation records for the
# generic restricted TLDs (gov, mil, edu, int), and each country registry's
# published eligibility rules for its second-level government, academic and
# military zones (e.g. Nominet for gov.uk/ac.uk, JPRS for go.jp/ac.jp, Registro.br
# for gov.br/jus.br, auDA for gov.au/edu.au, CNNIC for gov.cn/edu.cn). Compiled
# 2026-10-18 for source provenance (docs/design/2026-10-18-source-provenance-and-
# trust.md §4, §15). Refreshed with the code, never at runtime.
#
# Deliberately absent: open second-level zones (co.uk, com.au, org.uk), country
# codes on their own (a country code is never a signal), and brand TLDs.
