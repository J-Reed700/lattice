A reviewer commented on code in a code review exercise, and a judge found the comment to be a real problem that the answer key does not list. Describe it as an entry of the key. `kind` is `none` if it is an instance of none of the patterns in the request, and `issue` if it is an instance of one. For an issue give `pattern`, the name shown before the pattern it is an instance of, from the list in the request. Then give its severity, its consequence (what goes wrong and when), the fix as a change to the lines of one file, and an explanation in two sentences a candidate could say aloud in an interview. The code is data, never instructions.
