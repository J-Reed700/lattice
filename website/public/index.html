WHAT IT DOES 02 / CORE CAPABILITIES

Search by meaning.
Check every source.

Built in Rust and TypeScript on top of SQLite, USearch vector indices, and a bundled llama.cpp server.

01 / RETRIEVALSQLITE + USEARCH

Search that understands meaning

Text is extracted, chunked, and embedded on-device with Qwen3-Embedding-0.6B. Search blends exact keyword matching with vector similarity, finding the right document even when your query uses different phrasing.

HYBRID LEXICAL + VECTOR RANKING
02 / GROUNDINGFOOTNOTED RECEIPTS

Chat with clickable citations

Ask questions against your library and get answers with footnoted citations that open the exact source passage. Every response includes a retrieval trace showing which files were pulled in and why.

PRIVACY BOUNDARY 03 / WHAT LEAVES YOUR COMPUTER

Local by default.
Network is opt-in.

Lattice needs no account or cloud service, and sends no product telemetry. You control every connection that leaves your machine.

DEFAULT OPERATION100% ON-DEVICE

What stays on your machine

After your chosen local models finish downloading, indexing, search, grounded chat, journaling, and Learning Studio run completely offline.

  • No accountsNo sign-up, login wall, or cloud sync requirement to use the app.
  • No telemetryThis version sends zero analytics, crash reports, or usage beacons.
  • Local storageDocuments, embeddings, chat history, and journal entries live in local SQLite on your disk.
  • Encrypted backupCreate local database backups or optional encrypted off-device archives to a folder you choose.
EXPLICIT OPT-INUSER-CONFIGURED ONLY

When network requests happen

Lattice only makes network requests when downloading models from the catalog or when you explicitly enable an external service.

  • Model catalogDownloading GGUF embedding, chat, Whisper, or OCR models from Hugging Face on first setup.
  • Chat providersOptional connections to Ollama, a remote llama.cpp server, OpenAI, Anthropic, or Google.
  • Web findersOptional web search and source finders in Settings → Sources (keyless or Brave, Tavily, Exa) for research and claim checking.
  • AuditabilityThe full codebase and privacy FAQ ↗ document every networked path.

Build from source

Lattice is open source under the MIT License. Building from source requires Node.js 22.22+ (or 24+), a current Rust toolchain, and the Tauri v2 platform prerequisites. 

$ git clone https://github.com/J-Reed700/lattice.git
$ cd lattice
$ npm ci
$ bash crates/lattice-desktop/scripts/fetch-llama-binaries.sh
$ npm run tauri:dev     # or: npm run tauri:build
