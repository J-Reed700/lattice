# Verification of the 2026-10-12 LLM-stack SOTA audit

*Verifier run 2026-10-12 against `main` plus the uncommitted tree. Every Lattice claim below was checked at the cited file:line with `sed -n`/`grep -n`; every external claim was checked by fetching the cited URL once (abstract page first, full HTML where the abstract did not carry the number). Paths follow the report's abbreviations.*

## Verdict

The report is more trustworthy on the Lattice side than on the runtime side. Every code citation I checked (about 40 file:line references across `llama_cpp/mod.rs`, `settings.rs`, `ctx_asm/mod.rs`, `tool_loop.rs`, `readiness.rs`, `config.rs`, `curated.rs`, the reranker, the verifier, the eval README and results) was accurate to within a line or two, and the eval numbers (0.7755 / 0.7640 / 533 ms / 24.9 ms) are exactly as stated. The external sources were real in every case I fetched, and the numbers quoted from them were right far more often than not (Qwen card sampling, Qwen3-Reranker table, stared bench, Unsloth KLD, #20225, #22384, #20837, 2608.29307, 2605.26128, 2501.10868, 2601.14152, 2606.19037, forge #54, NodeNestor). The report's largest error is factual and load-bearing: the sidecar pin `v0.6.0` is an **upstream llama.cpp release dated 2026-10-05**, one week old, and MTP landed in b9180 on 2026-05-16, so "the llama.cpp pin predates MTP" and "the team strips MTP tensors" are both false (the blk.32 note in memory was about b8981, a *previous* pin; no stripping code exists). That removes item 8's upgrade and reorders the top five. The second-largest problem is an inference error in item 1: the report cites #20837 (Qwen3.5-9B writes tool calls inside `<think>` and the grammar ends generation; thinking off fixes it) and then recommends thinking **on** for exactly the tool-using call types, while also missing that the official Qwen3.5 template strips prior-turn reasoning, which is the prefix mutation ggerganov himself blames in #22384. After verification the top five become: (1) explicit `enable_thinking` + per-mode sampling, with thinking **off** for tool rounds; (2) byte-stable prefix, now including the reasoning-strip mechanism and `--checkpoint-min-step`; (3) evaluate what ships; (4) catalog refresh, which no longer waits on a build upgrade because the pinned build already knows `qwen35moe` and `gemma4`; (5) reranker swap. Compression (old #4) drops a few places: the data already settle it, the gain is one point on a synthetic fixture, and it costs 16x vector bytes.

## Revised ranking (payoff per unit of effort, surviving items only)

1. **Explicit `enable_thinking` and per-mode sampling on every request**, with thinking **off** for any round that offers tools (chat, Explorer, deep-research rounds), off for intent/HyDE/planner/router/judge/memory, and on only as a tested option for tool-free turns. Add `presence_penalty`. Hours to a day. (Item 1, corrected.)

Log cached vs evaluated prompt tokens first. Days. (Item 2, corrected; now paired with item 12's date-in-final-message.)
